- No STL containers will be used to implement any data structures (that includes std::vector).

Included data structures:
- Dynamic arrays.
- Hash tables.
- Linked lists.
- Trees.

Included search algorithms:
- Linear search.
- Binary search.

Included sorting algorithms:
- Bubble sort.
- Counting sort.
- Inserting sort.
- Merge sort.
- Quicksort.
- Radix sort.
- Selection sort.
